# CE-102 · Engineering Mechanics — Resource Hub

A clean, dark-themed, single-page web app that organizes all **CE-102 Engineering Mechanics** study materials in one place.  
Built with plain HTML, CSS, and JavaScript — no build tools, no dependencies, just open and use.

## ✨ Features

- **6 Resource Categories**  
  Topics · Notes · Classes · Exercise Solve · Previous Year Questions · Extra Honey

- **Expandable Chapters**  
  Each category is divided into collapsible chapter cards. Open one or expand all at once.

- **Live Search**  
  Filter resources instantly by title or metadata within the active category.

- **Video Modal Player**  
  YouTube lectures open in a centered modal with autoplay, keeping your place in the list.

- **PDF & Link Support**  
  Notes, solutions, and PYQs open in a new tab (just point them to your hosted files).

- **Dark, Modern UI**  
  Built with Poppins, Font Awesome, and a custom dark palette — easy on the eyes for long study sessions.

- **Fully Responsive**  
  Works beautifully on desktop, tablet, and mobile.

- **Zero Dependencies**  
  One HTML file. No npm, no bundler, no framework.
